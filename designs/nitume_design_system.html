Usage rules

  • Text & nav: #0B2545 is the only color for primary text, headings and navigation surfaces.
  • Backgrounds: cards and primary content sit on #FFFFFF; the app canvas and separators between cards use #F4F6F9.
  • Action green #04AF4D is reserved for primary buttons, active toggles, checked/complete states — never used decoratively.
  • Contrast: any label placed inside a green or blue filled surface uses #FFFFFF text — never dark text on green.
  • Fira Sans for every UI label, description, task text and button. Fira Code is reserved for numeric data only: timestamps, due dates, prices, counters like 3/5, ratings, ETAs.
  • Amber and red exist only as small semantic accents for "pending" and "disputed/failed" states — they are not brand colors and never appear as backgrounds larger than a chip.
